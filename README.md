# PhaseShifter Lab

Программный комплекс моделирования и исследования системы измерения параметров
цифровых фазовращателей. Веб-приложение воспроизводит полный цикл автоматизированного
измерения: модель объекта измерения, векторный измерительный тракт с погрешностями,
расчёт параметров с заключением «годен / не годен», бюджет неопределённости,
сравнение методов измерения фазы и применение результатов для калибровки ФАР.

Сборка не требуется: приложение написано на чистых модулях ECMAScript, работает
в браузере без Node.js, npm и внешних библиотек.

## Возможности

| Вкладка | Что моделируется | Графики |
| --- | --- | --- |
| Измерительный стенд | Измерение всех 2ᴺ состояний фазовращателя в диапазоне частот; сравнение измеренных параметров с истинными | полярная диаграмма состояний, фаза от частоты, ошибка по состояниям, СКО ошибки от частоты, тепловая карта, погрешность измерения, потери, КСВН, DNL, запись ПЧ, спектр ПЧ |
| Бюджет неопределённости | Монте-Карло: вклад шума, квантования, рассогласования, утечек, неидеальности тракта и дрейфа | гистограмма, вклады в u(φ) и u(потерь), неопределённость по состояниям |
| Методы измерения фазы | Пять методов на одних и тех же записях: ДПФ, квадратурный демодулятор, фазовый детектор, переходы через ноль, шестиполюсник | СКП от ОСШ с границей Крамера — Рао, систематическая погрешность от разности фаз |
| Применение в ФАР | Выбор состояний по номиналу и по таблице калибровки, составленной по результатам измерения | диаграмма направленности, главный лепесток, фазовые ошибки элементов |

Каждый график сохраняется в PNG (1904 × 1120 точек, всегда в светлой теме — для
пояснительной записки), все графики вкладки — в PDF, данные — в CSV (разделитель «;»,
десятичная запятая, открывается в Excel без настройки). Протокол измерения формируется
в PDF с таблицей параметров, заключением и оценкой точности.

## Запуск на своём компьютере

Модули ECMAScript не загружаются по протоколу `file://`, поэтому нужен любой
статический сервер. Например, встроенный сервер Python:

```bash
python -m http.server 8020
```

Затем открыть `http://127.0.0.1:8020/`. Самотест ядра — `http://127.0.0.1:8020/tests/`,
сверка с эталонной моделью — `http://127.0.0.1:8020/reference/`.

## Развёртывание на Vercel

Node.js, платные тарифы и сертификаты не нужны: HTTPS для адреса `имя.vercel.app`
Vercel выпускает автоматически.

1. Создать репозиторий на GitHub и отправить в него содержимое этой папки:

```bash
git init
git add .
git commit -m "PhaseShifter Lab"
git branch -M main
git remote add origin https://github.com/ПОЛЬЗОВАТЕЛЬ/РЕПОЗИТОРИЙ.git
git push -u origin main
```

2. На `vercel.com` выбрать **Add New → Project** и указать репозиторий.
3. В настройках сборки выбрать Framework Preset **Other**, поля Build Command
   и Output Directory оставить пустыми.
4. Нажать **Deploy**.

Все расчёты выполняются в браузере, серверные функции не используются. Это сделано
намеренно: пересчёт при движении ползунка занимает около 0,1 с, нет холодного старта
и ограничений бесплатного тарифа на время выполнения функций, а приложение работает
и без интернета — достаточно открыть папку локальным сервером.

## NumPy на сайте

Эталонная модель `reference/model.py` написана на Python с NumPy. На странице
`reference/` её можно запустить прямо в браузере: Python и NumPy загружаются через
Pyodide (около 15 МБ, один раз), модель считает все режимы из `cases.json`, и результаты
сравниваются с веб-версией число в число. Та же модель запускается и локально:

```bash
python reference/model.py          # таблица результатов по режимам
python reference/model.py --json   # сохранить результаты в reference/python_results.json
```

## Проверка корректности

**Самотест** (`tests/`, 36 проверок) сверяет расчёт с аналитикой: точность идеальных схем
разрядов на расчётной частоте, взаимность и пассивность модели, совпадение шумовой
погрешности фазы с формулой σ² = (1 + 1/|S21|²)/(2·ОСШ), ограничение погрешности
рассогласования оценкой первого порядка, линейный рост погрешности от дрейфа,
независимость относительной фазы от неидеальности тракта, достижение методом ДПФ границы
Крамера — Рао, УБЛ равномерной решётки −13,2 дБ, воспроизводимость по зерну генератора.

**Эталонная модель на Python** повторяет тракт вместе с генератором псевдослучайных чисел
и порядком операций, поэтому сравнение поразрядное. Сверка 11 режимов (2172 значения)
показала наибольшее относительное расхождение 2·10⁻¹³ — это уровень округления чисел
двойной точности.

## Принятые допущения модели

Разряды рассчитаны по формулам проектирования на расчётной частоте: ФВЧ/ФНЧ — симметричные
Т-звенья, нагруженная линия — конденсатор, коммутируемый ключом, со средней проводимостью,
поглощённой укорочением линии, переключаемые линии — два отрезка разной длины. Ключ открыт —
сопротивление Ron, закрыт — ёмкость Coff, через которую проходит утечка второго канала.

Измерительная система моделирует векторный анализатор цепей в прямом направлении.
Относительный фазовый сдвиг отсчитывается от состояния 0, положительное значение — задержка.
Остаточные члены модели ошибок заданы модулями, их фазы и групповые задержки случайны.
Шум задан коэффициентом шума и полосой ПЧ, квантование АЦП моделируется по отсчётам записи.
В основном измерении дрейф задан детерминированно, в прогонах Монте-Карло его скорость
равномерно распределена в пределах заданного значения.
